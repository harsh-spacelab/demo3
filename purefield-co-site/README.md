# Purefield Co. concept site

A responsive, framework-free dairy brand landing page built with HTML, CSS, and a small JavaScript file for the mobile navigation.

## Preview

Open `index.html` in a browser. The page uses Google Fonts and two remotely hosted Unsplash photos, so those parts need an internet connection.

## Customise before launch

- Replace the Purefield Co. name, product descriptions, and sample INR prices with the real brand and catalogue.
- Update the product and sourcing copy so it reflects the actual business.
- Replace the sample photos with approved brand photography if needed.
- Connect any ordering or contact links to the business's real order flow.
